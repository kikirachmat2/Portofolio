# Kiki Rachmat Portfolio

Portfolio for Kiki Rachmat, a film producer, line producer, and unit production manager.

## Stack

Next.js, TypeScript, and Tailwind CSS.

## Local development

```bash
npm install
npm run dev
```

Edit portfolio data in `src/data/projects.ts` and coding projects in `src/data/coding-projects.ts`.

Website: https://kikirach.vercel.app
